# Interview & code-review practice — free resource list

Every resource below is **free** and from an authoritative source (verified live before it was added). Use them to
prepare for the exercises in the `code-review-practice` and `cyber-review-practice` channels.

Two ground rules: **do not copy interview answers** — the point is to be able to explain your own reasoning out loud.
And any intentionally vulnerable example in the practice channels is a **learning artifact, never safe production
code** — the flaws are labeled on purpose.

Levels: **Beginner** (new to the language/tool), **Intermediate** (comfortable, building small things),
**Undergraduate Challenge** (combining familiar skills on a bounded project).

## Python fundamentals
- **The Python Tutorial** — https://docs.python.org/3/tutorial/index.html
  The official language tutorial: data types, control flow, functions, classes, the standard library. *Beginner → Intermediate.*

## JavaScript fundamentals
- **MDN JavaScript Guide** — https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide
  Mozilla's guide to JS grammar, functions, objects, promises and modules — the reference professionals actually use. *Beginner → Intermediate.*

## Git & GitHub pull-request workflow
- **GitHub Pull Requests documentation** — https://docs.github.com/en/pull-requests/collaborating-with-pull-requests
  How to create, review, and merge pull requests, resolve conflicts, and work with forks. *Beginner.*
- **GitHub Skills (interactive courses)** — https://learn.github.com/skills
  GitHub's own free, hands-on courses, including opening and reviewing pull requests inside a real repo. *Beginner.*

## Testing & debugging
- **Python `unittest`** — https://docs.python.org/3/library/unittest.html
  The built-in test framework: test cases, assertions, fixtures, and `python -m unittest`. Start here for writing tests. *Beginner.*
- **pytest** — https://docs.pytest.org/en/stable/
  A widely used test runner with less boilerplate and powerful fixtures; good once `unittest` feels natural. *Intermediate.*
- **Python debugger (`pdb`)** — https://docs.python.org/3/library/pdb.html
  Set a `breakpoint()`, step through code, inspect variables, and do post-mortem debugging instead of guessing with print statements. *Beginner → Intermediate.*

## Secure coding
- **OWASP Cheat Sheet Series** — https://cheatsheetseries.owasp.org/
  Concise, high-value guidance on 150+ application-security topics: input validation, SQL injection, secrets management, authentication. Read the ones that match your project. *Beginner → Intermediate.*

## Interview problem-solving & introductory algorithms
- **Harvard CS50x — Introduction to Computer Science** — https://cs50.harvard.edu/x/
  A free, complete intro to CS: computational thinking, algorithms, data structures, in C, Python, SQL and web. Great foundation for interviews. *Beginner.*
- **MIT OpenCourseWare 6.006 — Introduction to Algorithms** — https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/
  Free lectures, notes, and problem sets on algorithms and complexity at an introductory-but-rigorous level. *Intermediate → Undergraduate Challenge.*
